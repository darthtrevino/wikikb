# Agent Memory

Agent memory is durable project knowledge that survives beyond one model session. WikiKB stores it as Markdown on the wiki's normal branch and retrieves it through the CLI, project skill, or issue workflows. Generated indexes are replaceable acceleration state, not durable claims.
